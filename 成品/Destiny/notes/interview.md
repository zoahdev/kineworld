# 试用任务与访谈问题（给真实用户，未授权前不要自行联系）

目标：验证**一个关键假设**——普通人愿不愿意为了"提前发现摆放问题"而花几分钟量尺寸、摆家具，
并且认为结果有价值。其他都是次要的。

## 一、试用任务（让用户自己做，不要替他做）

准备：用户本人一部手机（拍照/量尺寸用）+ 一台电脑。全程 10–15 分钟。

1. 说一句：「请你用自己真实的一个房间来做：宿舍床位、出租屋、自己家卧室都行。」
2. 让用户**报出或量出**房间的长宽（没有卷尺就用手机步测或看租房合同/户型图）。
3. 让他自己填进工具，选模板，把真实家具（床、桌、柜等）拖进去。
4. 让他自己看右边的问题清单，读出来。
5. 打开热力图，问他哪里是红的。

**不要提示、不要替他操作、不要解释应该怎么摆。** 他卡住的地方就是我们要的信息。

## 二、观察并记录（现场填，不要事后回忆）

| 观察项 | 记录 |
|---|---|
| 他量/填房间尺寸花了多久 | |
| 是否在填尺寸这一步就放弃或敷衍 | |
| 摆放过程中卡住的地方（原话） | |
| 他自己完成到哪一步 | |
| 工具报出的问题，他认不认可（"我家确实是这样"） | |
| 有没有报出他觉得是**错的**问题 | |
| 有没有**漏掉**他真实遇到过的问题 | |

## 三、访谈问题（先问过去真实发生的事，再问感受）

1. 上一次你搬家具/布置房间是什么时候？当时有没有出现"放不下""打不开""走不过去"的情况？具体是什么？
2. 那次你是怎么发现问题的？提前想到了，还是搬完才发现？代价是什么（退货、返工、忍着用）？
3. 刚才这个工具报出来的问题里，有哪一个是你**以前真的踩过的坑**？
4. 有哪一条你觉得是**瞎说**的？为什么？
5. 如果下周你又要布置一个房间，你会打开它吗？为什么？
6. 你觉得它应该先帮你解决什么，才会让你愿意用第二次？
7. 如果它继续做下去，你愿意为它付钱吗？大概多少？什么情况下愿意？（问完请注明：这只是口头意向，不算收入。）

## 四、诚实记录要求

- 区分「用户说的原话」和「我的推测」，推测单独标注。
- 朋友/同学的夸奖**不算**市场验证，只记录"是否愿意再次使用"和"是否有明确付费意愿"两栏。
- 记录前征得同意；公开引用（包括截图）要单独再问一次。
- 不虚构反馈；没人用过就写"尚未验证"。
- 最少必要原则：不收集姓名、电话、身份证、照片等无关信息。

## 五、本轮判定标准（先写死，避免事后自我说服）

- **继续做**：找 5–8 个真实用户，其中至少 3 人**自己**完成量尺寸 → 摆放 → 看清单的全流程，
  且至少 2 人能说出"这个坑我踩过"。
- **调整**：多数人愿意用但卡在输入尺寸 → 改为更轻的输入方式（拍照估、只填几个关键尺寸）。
- **缩小或换方向**：多数人根本不想量尺寸，或认为"我自己看看就知道" → 说明价值假设不成立，
  回到 `direction-options.md` 的方向 B / C，或重新找场景。
