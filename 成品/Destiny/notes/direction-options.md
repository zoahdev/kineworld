# Destiny 候选方向（第一版，2026-09-11）

评估标准：普通人 10 分钟内能获得价值 / 能低成本做原型（零新增预算）/ 与「互动·模拟·空间·行动后果」有真实联系 / 不依赖训练模型或买算力 / 能找到可接触的真实用户。

以下三个方向均为我基于本地环境与常识提出的**待验证假设**，尚未经过任何用户验证，也未做联网核查（本轮未联网搜索）。

---

## 方向 A：小空间布局与动线检查（宿舍 / 出租屋）

1. **谁在什么情况下需要它**
   大学新生入学前想知道床、桌、柜怎么摆；租房青年搬家前想知道"我这套家具放不放得下、放进去还能不能走"。典型时刻：看房后、下单家具前、搬家当天。

2. **现在怎么解决，哪里不满意**
   卷尺量 + 脑子里想；画在纸上 / 备忘录；问室友；看小红书效果图（户型不一样，抄不了）。硬伤是：**错误在搬完家之后才暴露**——柜门打不开、过道只剩 40cm、插座被床挡住、窗户被柜子堵死，返工成本极高。

3. **用户会得到什么**
   在平面图上摆家具 → 立即得到一份"问题清单"：哪里放不下、哪里重叠、哪条路走不通（通道净宽 < 60cm）、柜门能不能开、床边够不够上下床、插座/窗户是否被挡。附带一张可保存的布局图。

4. **能否零新增预算做出原型**
   能。纯浏览器 + Canvas + 自写规则引擎（几何碰撞、距离场、路径连通性），不调用任何 API，不训练模型，不依赖第三方库。人体工程学尺寸采用公开常用建议值。

5. **如何找到真实试用者**
   创始人本人是在校学生：宿舍室友、同班同学、新生群、租房同学。试用任务可在 5 分钟内完成（选模板 → 拖家具 → 看清单）。不需要注册账号，不需要上传数据。

6. **主要失败风险**
   - 用户嫌"量尺寸 + 摆家具"太麻烦，宁愿继续脑补（最大风险，必须在第一轮就验证）。
   - 用户觉得"这些问题我自己也看得出来"，价值感不足。
   - 规则太粗，报出一堆无关痛痒的提示，反而降低可信度。
   - 与酷家乐/躺平设计家等成熟产品重叠（但它们是重型 3D 家装工具，上手成本高、偏装修而非"能不能用"）。

## 方向 B：重要对话的预演沙盘

1. **谁在什么情况下需要它**
   要和室友谈作息、向老师申请延期、跟家里要生活费、第一次谈薪、拒绝别人之前，想先在"安全的地方"走一遍。

2. **现在怎么解决，哪里不满意**
   在脑子里排练、找朋友模拟、直接问 AI（AI 角色扮演容易迎合、记不住状态、说完就忘，也不是"可复现的世界"）。

3. **用户会得到什么**
   设定对方的三四个状态变量（情绪、信任、诉求强度），每说一句，状态按规则变化；结束后给出"哪句话把对方推远了、换个说法会怎样"的复盘。

4. **能否零新增预算做出原型**
   能。规则状态机 + 示例对话库，本地运行。

5. **如何找到真实试用者**
   学生群体高频场景（宿舍沟通、社团、兼职面试）容易征集。

6. **主要失败风险**
   - 极易被看成"套壳聊天"，与公司"世界模型"方向的真实联系弱。
   - 涉及心理与现实人际决策，必须做风险提示，不能声称能预测真实的人。
   - 用户用一次就够，留存和付费点都不清晰。

## 方向 C：一天的行程可行性模拟

1. **谁在什么情况下需要它**
   学生/预算有限的年轻人做周末或短途出行规划时，把 N 个地点排进一天。

2. **现在怎么解决，哪里不满意**
   抄小红书攻略、用地图 App（只算交通，不算游览时长、排队、体力、闭馆时间）。结果是"排了 6 个点，实际只走了 3 个"。

3. **用户会得到什么**
   输入地点清单与预计停留 → 得到"真实可行的时间表 + 卡在哪个点 + 砍掉哪个最划算"。

4. **能否零新增预算做出原型**
   能，规则模型即可（步行速度、停留时长、体力衰减、营业时间）。

5. **如何找到真实试用者**
   出行前的人群很好找，也乐于分享结果。

6. **主要失败风险**
   - 景点停留时长/排队数据无预算获取，只能让用户自己填，价值感下降。
   - 与地图 App、AI 行程规划正面重叠，護城河弱。
   - 与"空间/世界模型"的联系偏弱，更像排程计算器。

---

## 选择结果：方向 A（小空间布局与动线检查）

理由：
1. **和世界模型的关系最硬**：它的本质就是一个可交互的空间状态——你做一个动作（挪家具），环境状态改变，规则给出后果（能不能走、门能不能开），而不是一段话术。
2. **用户就在身边**：安徽大学在校生，宿舍/租房场景的试用者可以当天拿到，不需要买流量或发广告。
3. **零成本且自证可信**：规则来自公开的常用人体工程学建议值，结果可以被用户拿卷尺当场验证——这是最有说服力的验证方式，也是区分"真实规则"和"想象生成"的地方。
4. **失败成本低**：即使被证伪，规则引擎、距离场与路径检查这部分能力可以复用到房屋/场景类其他产品。

方向 B、C 暂不开发，保留在本文档作为备选。
