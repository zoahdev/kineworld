# 数据来源与许可证记录（Destiny 原型 v0.1）

原则：代码、模型权重、数据是三件事，分别记录；不确定的一律标注「未核实」，不编造来源。

## 1. 代码

| 内容 | 来源 | 许可证 | 说明 |
|---|---|---|---|
| `prototype/index.html`、`styles.css`、`app.js` | 本项目自写 | MIT（本项目） | 无第三方库、无 CDN 资源、无外部字体 |
| `prototype/catalog.js`、`rules.js` | 本项目自写 | MIT（本项目） | 规则引擎，纯本地计算 |
| `server.js`、`启动原型.bat` | 本项目自写 | MIT（本项目） | 零依赖，仅监听 127.0.0.1 |
| `tests/*.js` | 本项目自写 | MIT（本项目） | 自检脚本 |

**第三方依赖：无。** 没有引入任何开源项目整库或片段，因此不涉及许可证兼容问题，也不需要署名第三方。

## 2. 模型 / 权重

**没有使用任何模型，没有权重文件，没有推理。** 原型不做「生成」，只做规则计算：
几何重叠、矩形包含、四分之一圆（门扇扫掠）、栅格距离变换、最大瓶颈路径。
因此不存在"用第三方模型自称自研"的风险。若未来接入模型，必须另起记录并注明模型名、版本与许可证。

## 3. 数据（尺寸与阈值）

### 3.1 已联网核实的公开标准

- **《住宅设计规范》GB 50096-2011 · 5.7.1**：套内入口过道净宽不宜小于 1.20m；
  通往卧室、起居室（厅）的过道净宽不应小于 1.00m；通往厨房、卫生间、贮藏室的过道净宽不应小于 0.90m。
  检索到的多个规范条文页面一致（soujianzhu.cn、gf.cabr-fire.com、firelaw.cn 等转载），
  但**未购买/查阅正式出版文本，条文以正式出版物为准**。
  重要：该条文针对的是**套内固定过道**，不是家具之间的空隙。原型里把它做成"90cm 严格标准"选项，
  仅作参考，**不能用来宣称合规**。

### 3.2 未核实的行业经验值（默认阈值）

以下数值来自室内设计/家具布置的**常见经验说法**，本次只在内容平台（今日头条、百度文库等）
见到相似表述，**未找到权威出处，标注为未核实**。它们只是"默认值"，用户可在界面上切到 90cm 标准：

| 阈值 | 默认值 | 用途 |
|---|---|---|
| 单人通行最小净宽 | 60cm | 判断家具之间能否走人 |
| 较舒适净宽 | 90cm | 热力图分档 |
| 床侧上下床空间 | 50cm | 床的一边是否够用 |
| 柜前取物/开门 | 60cm（冰箱 90cm） | 柜门能否打开、人能否蹲下取物 |
| 桌前就坐与起身 | 60cm | 椅子拉出与起身 |
| 窗前空间 | 60cm，遮挡判定高度 ≥120cm | 是否被高家具挡住 |

### 3.3 家具尺寸

`catalog.js` 中的家具尺寸是**常见规格的估算值**（如单人床 90×190、书桌 120×60、衣柜 90×60），
来源是常见商品规格的一般印象，**未经任何厂商或标准核实**，用户可自行修改。

### 3.4 房间模板

`dorm-4` / `rent-studio` / `bedroom` 三个模板的尺寸**是示例估算值，不代表任何具体学校或小区**。
界面上已强制标注。真实使用时必须由用户按实际测量值修改，否则结论无意义。

## 4. 需要补做的核实（负责人/创始人可决定优先级）

1. 购买或查阅 GB 50096-2011 正式文本，核对 5.7.1 原文与适用范围。
2. 为 3.2 表中的经验值找到可引用的公开来源，或明确改为"用户可调参数"而不称建议值。
3. 若要把结论用于付费场景，需要区分"提示"与"合规判断"，并加入免责与人工复核环节。
