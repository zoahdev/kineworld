# Destiny 原型 v0.1 —— 小空间布局与动线检查

一句话：在平面图上摆家具，立刻知道「放不放得下、走不走得通、门开不开得了」。

## 它现在能做什么

- 拖动摆放家具，可旋转、删除、方向键微调（5cm）、撤销、复制一份
- 家具可直接用鼠标**拉伸**：选中后拖四个角或四条边上的小方块改尺寸（改错了按「恢复默认尺寸」）
- 门和窗也可以用鼠标**拖动**和**拉伸**：拖着门沿墙走，拖到别的墙会自动换墙；拖两端的小方块改宽度；**双击门**换个方向开
- 一键贴左/右/上/下墙、居中、清空
- 实时给出问题清单：放不下、家具重叠、门打不开、**门口被堵**、柜前被挡、床边不够、插座被埋、窗户被挡
- 判断「从门口能不能走到床/桌子/柜子」，并给出这条路上最窄处大约多少厘米
- 通行宽度热力图，让你看见哪里挤；通行标准可切换 60cm / 90cm
- 点问题清单里任意一条，会自动选中对应的家具
- 「复制结论文本」：把结论复制成文字，方便发给别人看
- 问题清单里**指向家具的条目可以点**（点了在图上高亮那件家具），**整间房/通道类的条目点不了**，
  会明确标出「不指向单件家具」——以前两类长得一样、点了没反应，容易被当成坏了
- 撤销会恢复你之前选中的那件家具（以前撤销一次选中状态就被清掉）
- 导出 PNG、保存到本机浏览器（不联网、不上传）

## 它不是什么（重要）

- **不是 AI 生成**：没有调用任何模型，全部是本地规则计算（几何 + 距离场 + 路径）。
- **不是专业设计工具**：阈值是行业经验值，房间模板是示例估算值，结论不构成设计或施工依据。
- **不是合规判断**：国家标准（《住宅设计规范》GB 50096-2011）对套内过道的要求是 0.90–1.20m，
  指的是固定过道；本工具默认用 60cm 判"能不能走人"，两者不是一回事，不能混用。
  详见 `notes/sources.md`。

## 怎么打开（推荐方式，一步一步来）

1. 打开文件夹 `世界模型\成品\Destiny`。
2. **双击 `启动原型.bat`**。
3. 会弹出一个黑色命令行窗口，并自动打开浏览器页面。
   看到画面里有房间和几件家具，就成功了。
4. **不要关闭那个黑色窗口**，关了页面就打不开了。用完直接关窗口即可。

如果双击后报错说找不到 node：需要先安装 Node.js（免费），到 https://nodejs.org 下载 LTS 版本，
一路点"下一步"安装完，再回到第 2 步。

另一种不需要 Node 的办法：直接双击 `prototype` 文件夹里的 `index.html`，用浏览器打开也能用。
区别只是不能点"导出 PNG"以外的一些功能（其余功能都正常）。

## 怎么用（30 秒体验）

1. 左上角「房间模板」选一个，或直接改宽/高，**填你自己房间的实际尺寸**。
2. 从「添加」里选家具，点「放进去」。
3. 用鼠标拖动家具摆到你想要的位置；选中后点「旋转 90°」或按 R 换方向；
   拖家具四周的小方块可以改它的长宽，门和窗也一样可以拖着走、拖两端改宽度。
4. 看右边的问题清单：红色是必须解决，黄色是提示。
5. 勾选「显示通行宽度热力图」，红色区域就是走不过去的地方。
6. 满意后点「导出 PNG」保存图片。

## 自检命令（需要用命令行时）

```
cd Destiny
node tests/rules-smoke-test.js     # 规则引擎（纯函数）
node tests/dom-id-check.js         # 界面元素引用
node tests/browser-check.mjs       # 真浏览器：真鼠标点击/拖拽/下载/弹窗/存档往返
```

三个都应该全部通过。

`browser-check.mjs` 会自己起本地服务、自己开一个无头 Chrome（或 Edge），用**真鼠标事件**
（不是 `element.click()`）走一遍 24 项检查：首屏渲染、点问题清单选中家具、按 R 旋转、
方向键微调、撤销、清空、添加、拖拽、改房间尺寸、保存到本机、读取上次、复制结论、
导出 PNG、热力图、切通行标准，并断言全程没有 JS 报错。

- 不需要联网，不需要安装任何 npm 包（用 Node 内置的 WebSocket 直接说 Chrome 调试协议）。
- 需要 Node 18+，以及本机有 Chrome 或 Edge；找不到时用 `CHROME_PATH` 指定。
- 想顺便留一张截图：`DESTINY_SHOT=/tmp/shot.png node tests/browser-check.mjs`。

## 版本记录（本地 git）

仓库根目录：`世界模型`（命令都要先 `cd 世界模型`）。Destiny 的所有内容都在 `destiny` 分支上，
**不碰 main 分支**，也就不会和 KineWorld 主线混在一起。

常用命令：

```
git status                 看改了什么
git branch --show-current  确认当前在 destiny 分支
git log --oneline          看提交历史
git add -A                 暂存所有改动
git commit -m "说明"        提交到本地
```

第一次提交时本机没有 git 身份，我用了临时身份 `Destiny Local <destiny@localhost>`（只在命令里生效，
没有改任何 git 配置）。你可以改成自己的：

```
git config user.name "你的名字"
git config user.email "你的邮箱"
```

**没有添加任何远程仓库，不会推送到网上。** 要备份的话，把整个 `世界模型` 文件夹复制一份即可。
