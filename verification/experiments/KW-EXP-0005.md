## ⚠ 事后更正（2026-09-02，跑批完成后的再分析）

本实验提交后做了两项零成本再分析，**部分推翻了下文 Q1 与 Q1b 的表述**。原结论保留以供审计，更正如下。

### 更正 1：「误差非单调、不存在复合增长」是 3 个离群点造成的假象

以 >4× 中位数（中位数 `0.03372`）为尖峰，90 个点中**仅 3 个**：

| episode | latent step | MSE |
|---|---:|---:|
| ep_4 | k=1 | 0.38512 |
| ep_10 | k=4 | 0.22690 |
| ep_8 | k=4 | 0.16986 |

**剔除这 3 个点后，各 k 均值基本单调上升**：

`0.02951 → 0.02608 → 0.03634 → 0.04315 → 0.03977 → 0.04337`

k=1 到 k=6 约 **1.5×** 增长。因此正确表述是：**存在温和的 horizon 增长，不存在指数级复合爆炸**；原文"非单调"的说法不成立，它是 3/90 个尖峰在小样本均值上的投影。

### 更正 2：「误差是 episode 特异的重尾」不准确，应为「点级稀疏尖峰」

单因素随机效应 ANOVA（15 episodes × 6 horizons）：

| 量 | 值 |
|---|---:|
| MS_between | 0.002204 |
| MS_within | 0.002247 |
| σ²_between | 0.000000（负估计，截断为 0） |
| **ICC** | **0.0000** |
| F（df 14,75） | 0.981 |

**episode 间方差为零。** episode 内亦无持续性：`corr(k1,k2)=0.1516`、`corr(k1,k4)=-0.0958`、`corr(k1,k6)=-0.2310`。

含义：误差结构**不在 episode 级**。ep_4 的中位误差 `0.03559` 属正常范围，它的 `0.3851` 是**单点尖峰**而非整段退化。原文把 ep_4 描述为"误差最大的 episode"是错的。

分布：偏度 **5.11**、峰度 **33.95**，p50 `0.03372`、p90 `0.06490`、p99 `0.24430` —— 重尾完全由这 3 个点造成。

- **被更正**：Q1 的"非单调"与 Q1b 的"episode 特异"表述。

## 0b. 索引对齐核验（重要：证伪了一个 bug 假设）

`unroll()` 返回 `[tau + T, ...]`（`tau` = context 前缀长度，`T` = 规划动作步数）。若 `tau=2`，则 `predicted[k]` 实为第 `k-1` 个 rollout 步，会使 EXP-0002～0004 的全部 latent 误差指标错位一个 action step。

实测：`predicted_len=7`、`plan_horizon=6` → **`tau = 7 - 6 = 1`**（`latent_index_offset=1`，15/15 段一致）。因此 `predicted[k]` **就是**第 k 个 rollout 步，`ctxt_window=2` 只是预测器滑动窗口长度，不是 context 前缀长度。

结论：**不存在错位 bug**，修正前后数值逐位相同（`aligned == legacy`，15/15 段成立）。EXP-0002 / 0002b / 0002c / 0003 / 0004 的既有结论**不受影响**。新增 `predicted_len` / `latent_index_offset` / `*_aligned` 字段用于审计。

## Q3 — Horizon 条件校准（Kill Criteria 触发）

| α | 方法 | 覆盖 | 平均上界 | 相对 pooled |
|---|---|---:|---:|---:|
| 0.10 | pooled | 0.9000 | **0.066455** | — |
| 0.10 | per-horizon | 0.9333 | 0.142660 | **+114.67%** |
| 0.20 | pooled | 0.8000 | **0.052124** | — |
| 0.20 | per-horizon | 0.8111 | 0.058245 | **+11.74%** |

- per-horizon 带在**两个 α 下都更宽**，且 α=0.20 下覆盖仅高 1.1pp → **严格劣于 pooled**。
- **机制**：每折每 horizon 层只有 n=14 个校准点。α=0.10 时保形分位水平 `ceil(15×0.9)/14 = 1.0`，即退化为**样本最大值**，导致上界爆炸。α=0.20 时 `12/14 = 0.857`，退化较轻，故劣化幅度也小。
- 因此在当前可行的样本量（15 episodes）下，horizon 分层**既无可提取的 horizon 信号（Q1 曲线平坦），又付出分位数退化的代价**。

## 结论

1. **停止 horizon-conditioned 校准**：预注册 Kill Criteria 已触发。
2. **停止把 horizon 当作不确定性条件变量**：本轮与 EXP-0003（spread）、EXP-0004（无原生方差）共同构成连续三个负面结果。
3. **误差的主导结构是 episode 特异的重尾，不是 horizon，也不是 CEM spread**。任何未来不确定性方法必须能解释 episode 间差异，否则没有可校准信号可用。
4. **"复合误差随 horizon 爆炸"在本设置下不成立**，不能直接用来解释 EXP-0001 中闭环重规划的失败。
5. **planner 乐观度弱且不稳定**，objective-mismatch 假设降级为弱支持。

## 下一步（KW-EXP-0006 候选）

误差的重尾与 episode 特异性提示：条件变量应是**物理状态**而非 horizon 或 planner 内部量。`infos` 中已有 `near_object` / `obj_goal_dist` / `obj_lift`，可检验"**接触/接近物体的物理状态**"是否能预测 latent 误差。这与本项目的物理 grounding 主线一致，且只需小幅埋点扩展。

## 证据等级与限制

- E1。单 seed、单 checkpoint、单任务 Push-T、15 episodes / 90 horizon 点。
- 每个 horizon 层 n=15，bootstrap CI 与保形分位数在小样本下均不稳定；α=0.10 的 per-horizon 带因分位数退化为样本最大值而不具参考价值。
- 保形有效性依赖 episode 间可交换假设；同一 episode 内 6 个 horizon 点强相关，leave-one-episode-out 折缓解但未消除该相关性。
- 中位数比均值更可靠（mean/median 最高达 2.43），报告结论以中位数为准。
