# KW-LEWM-0005d — 同一 50 任务上的「无模型」对照臂

**证据等级**：E1（单平台、单任务集、每个模型臂单 checkpoint）
**算力**：纯 CPU，无 GPU，无世界模型。真实 rollout（0005c 是事后再分析，本实验不是）
**脚本**：`verification/scripts/kw_lewm_0005d_modelfree_reference.py`
**结果**：`results/kw_lewm_0005d_modelfree_reference.json`（17.3 KB，判据自校验一致率 **1.000**）

---

## 1. 为什么必须做这个实验

KW-LEWM-0005c 在严格配对的 50 个任务上比较 LeWM（18/50）与 JEPA-WM（1/50），并引入了一个**解析式** no-op 基线。它留下两个洞，而且这两个洞正是审稿人第一刀会砍的地方：

1. **no-op 是解析的，不是跑出来的。** Push-T 的 `_set_state` 会把**专家当帧的 agent 速度**一起注入，且 `space.damping = 0`。零动作策略并不等于「冻结」——PD 项要先把一个已经以 ~190 px/s 运动的 agent 刹住。解析假设（final == start）可能不成立。
2. **完全没有无模型控制对照。** 「JEPA-WM 花掉同样的位移预算但目标进展为负」只有在**无模型随机策略不这样**时才有意义。对一个起点距目标 123 px 的随机游走来说，「越走越远」本来就是零假设。所以 0005c 的措辞「主动远离目标」有可能把任务几何算到了模型头上。

本实验用**纯 CPU、不加载任何世界模型**的真实 rollout 同时补上这两个洞：同一个环境、同样 50 个数据集任务、同样 50 步预算、同样的执行侧 action scaler，唯一区别是动作来自固定分布而不是 planner。

## 2. 三个无模型臂

| 臂 | 动作 | rollout 数 |
|---|---|---|
| `noop_zero_action` | `a = [0, 0]`（env 空间） | 50（确定性） |
| `cem_prior_random` | `a ~ N(scaler.mean, scaler.scale)`，即 **`inverse_transform` 之后的 CEM 先验**——「零模型信息的 planner」 | 50 任务 × 100 种子 = 5000 |
| `uniform_random` | `a ~ U(-1,1)^2`，箱内最大随机努力 | 5000 |

成功判定**直接调用环境自己的** `eval_state`，不重新实现。此外用 0005c 的几何函数重建标签做 R0 自校验，三臂一致率均为 **1.000**。

## 3. 预注册假设与判据（计算前写死）

判据刻意做成**与种子数 S 无关**。对「1 次成功」的观测，Poisson-binomial 尾概率是 S 的单调函数（种子越多零假设越紧、p 越小），拿它当主判据等于让预算决定结论。因此主判据是：

> `U` := 无模型臂**逐 rollout** 成功率的单侧 95% Wilson 上界（跨任务 × 种子池化），取各臂最大值。
> 模型臂的 Wilson 下界 > `U` ⇒ 越过地板；否则未越过。

Poisson-binomial 尾概率仍然算、仍然登记，但**只作为敏感性分析**并注明其 S 依赖性。

## 4. 结果一：无模型地板不是零，而且 JEPA-WM 没越过它

| 臂 | 成功 | 逐 rollout 率 | 任务级率（cluster bootstrap 95%） |
|---|---|---|---|
| `noop_zero_action` | 0 / 50 | 0 | 0.000 |
| `cem_prior_random` | **197 / 5000** | **3.94%** | [1.88%, 6.34%] |
| `uniform_random` | 158 / 5000 | 3.16% | [1.76%, 4.78%] |
| **JEPA-WM (0005)** | 1 / 50 | **2.00%** | Wilson [0.35%, 10.50%] |
| **LeWM (0004)** | 18 / 50 | **36.0%** | Wilson [24.14%, 49.86%] |

地板界 `U = 0.0452`。

* **JEPA-WM**：Wilson 下界 0.0035 < `U` ⇒ **`JEPA_NOT_ABOVE_MODEL_FREE_FLOOR`**。点估计 2.0% 甚至**低于**两个随机臂（3.94% / 3.16%）。配对 McNemar（seed 0 切片）：vs CEM 先验 1 vs 2、p = 1.0；vs uniform 1 vs 1、p = 1.0。
  ⇒ **JEPA-WM 的闭环表现与「从它自己的 CEM 先验里随机采动作」在统计上无法区分。** 模型给出的选择没有带来任何可测收益。
* **LeWM**：Wilson 下界 0.2414 ≫ `U` ⇒ **`LEWM_ABOVE_MODEL_FREE_FLOOR`**，约为无模型地板的 **9 倍**。配对 McNemar：vs CEM 先验 **17 vs 1，p = 1.45e-4**；vs uniform 18 vs 1，p = 7.63e-5；vs no-op 18 vs 0，p = 7.63e-6。
* **反驳守门（H1c）**：随机臂最高 3.94% < 0.30 ⇒ `PLATFORM_TASKS_NOT_RANDOM_SOLVABLE`。任务集不是随机可解的，0004/0005 的同台比较框架成立。

敏感性（不作主判据）：Jeffreys 平滑下 P(X≥1) = 0.914、P(X≥18) = 5.2e-17；MLE 下 0.891 / 0.0；Wilson 上界下 0.993 / 7.5e-9。三种估计下结论方向一致。

## 5. 地板为什么不是零：预写猜测被数据否证

我在跑之前写下的机制猜测是「地板来自 block 位姿本来就在容差内的任务」。**该猜测被数据否证**，按纪律保留在 JSON 里（`initial_guess_status: REJECTED_BY_DATA`）：

| 关系 | Spearman ρ |
|---|---|
| 随机成功次数 vs `block_gap_start` | **+0.017（无关）** |
| 随机成功次数 vs `agent_gap_start` | **−0.530** |
| 随机成功次数 vs `pos_gap_start`（4 维） | −0.527 |

block 已在容差内的 16 个任务上随机成功率 5.4%，其余任务 3.2%——差异温和，不是驱动因素。

**真正的机制是 agent 导航项**：随机动作能成功的任务，是那些 **agent 起点本来就靠近专家 goal_step 时刻 agent 位姿**的任务（50 个任务里 17 个出现过至少一次随机成功）。这与 0005c 的失败项归因（85.7% 由 agent 位置项主导）一致，也再次说明这是**4 维联合判据的性质**，不是物体操作能力的体现。

## 6. 结果二：0005c 的解析 no-op 成立

| 量 | 实测（真实 rollout） |
|---|---|
| 成功 | **0 / 50**（解析预测 `solved_at_start` = 0/50 ✓） |
| block 位移 中位数 / 最大 | **0.00 / 4.14 px** |
| agent 漂移 中位数 / 最大 | 3.50 / 14.17 px（初速刹车导致） |
| block-only 放松判据成功率 | **0.32 = 16/50**（0005c 解析值 16/50 ✓ 完全吻合） |

⇒ `ANALYTIC_NOOP_VALID`。0005c 的 H1 结论（no-op 0/50、LeWM 显著优于 no-op）不需要修改。

## 7. 结果三：位移努力不是区分轴（确认 0005c）

| 臂 | `agent_disp` 中位数 |
|---|---|
| `noop_zero_action` | 3.50 |
| `cem_prior_random` | 93.94 |
| **LeWM (0004)** | **131.28** |
| **JEPA-WM (0005)** | **132.40** |
| `uniform_random` | 191.98 |

JEPA 的 132.4 落在随机臂区间 [93.9, 192.0] 内 ⇒ `EFFORT_NOT_DISCRIMINATIVE`；且 LeWM 与 JEPA 几乎相同（131.3 vs 132.4），再次确认 0005c 的「同等位移预算」。

## 8. 结果四（关键修正）：等位移匹配后，JEPA 的方向与随机游走无法区分

H4 原始判据给出 `MIXED`：CEM 先验臂的 `pos_progress` 均值 −7.38、CI [−18.53, +3.66] **含 0**（近乎无偏）；uniform 臂 −107.04、CI [−116.37, −97.45]（强负）；JEPA −45.38、CI [−68.55, −21.53] 夹在中间。

这暴露了一个混淆项：**JEPA 动得比 CEM 先验臂多 1.4 倍**，负进展可能只是「动得多」。于是补一个**事后探索性**（明确非预注册）的等位移匹配对照：逐任务只保留 `agent_disp` 与该任务模型臂位移相差 ≤15% 的无模型 rollout（两个随机臂池化，匹配池中位数 29–30 条），50 个任务全部匹配成功。

| 模型臂 | `agent_progress` 配对差（模型 − 等位移随机） | 判定 |
|---|---|---|
| **JEPA-WM** | **+4.21，CI [−11.58, +20.46]（含 0）** | `JEPA_DIRECTION_INDISTINGUISHABLE_FROM_MATCHED_RANDOM` |
| **LeWM** | **+124.20，CI [98.19, 152.05]** | `LEWM_DIRECTION_BETTER_THAN_MATCHED_RANDOM` |

`pos_progress`（4 维）配对差同向：JEPA +0.19、CI [−15.47, +17.07]；LeWM +125.82、CI [99.30, 154.44]。

**因此必须修正 KW-LEWM-0005c 的措辞。** 0005c 写「JEPA 的 `pos_progress` 显著为负 ⇒ 主动远离目标」——在**没有等位移对照**的前提下，这句话把随机游走的几何效应算成了模型行为。修正后的正确表述是：

> JEPA-WM 的目标进展**就是同等位移随机游走的水平**：不更好，也不更差。

这不是把结论削弱，而是把它变成**更纯粹的弱动作条件读数**——模型对方向的贡献是**零**，而不是「负」。

附一个描述性量（不作判据）：单位位移进展 `mean(agent_progress)/mean(agent_disp)` 为 LeWM +0.642、no-op +0.208、CEM 先验 −0.075、JEPA **−0.269**、uniform −0.517。它看上去说 JEPA 比 CEM 先验更差，但这是跨任务的聚合比值，同时混入了任务几何与努力量；**逐任务、等努力的配对分析（上表）同时控制了这两者，应以配对结果为准**。两者的表面张力必须一并登记，不得只报对自己有利的那一个。

## 9. 结论

1. **LeWM 0004 的 0.36 是真实的目标导向控制**（第四条独立证据）：约为无模型地板的 9 倍，配对 McNemar p = 1.45e-4，且等位移匹配后方向优势 +124.20 CI [98.19, 152.05]。
2. **JEPA-WM 在本平台上的闭环表现无法与无模型随机区分**：既没越过地板（点估计还更低），等位移匹配后方向差异也含 0。这是 §8「弱动作条件」最直接的行为学表述——**planner 的模型选择没有带来任何方向性收益**。
3. **本任务集不是随机可解的**（3.94% ≪ 36%），同台比较框架成立。
4. **0005c 的解析 no-op 成立**（0/50、block-only 16/50 完全吻合），但 0005c 的「主动远离目标」措辞**被本实验修正**为「与等位移随机不可区分」。

## 10. 局限与不得越界的地方

* E1：单平台、单任务集、每个模型臂单 checkpoint、单 planner 预算。**不得**声称官方 benchmark 复现，**不得**声称 JEPA-WM 模型本身能力弱——本实验只约束「该 checkpoint 在该 `get_cost` 包装 + 该 CEM 预算下的闭环表现」。
* 无模型臂是逐步 i.i.d. 的；真实 planner 每次规划执行 5 步 action block。因此 `cem_prior_random` 是 planner 的**先验**，不是它的时间相关性结构。
* no-op 现在是真实 rollout，但注入了专家初速；本环境里「硬冻结 agent」物理上不可实现。
* H5 是**事后探索性**分析（动机来自 H3/H4 的结果），不得作为预注册结论引用。
* Poisson-binomial 尾概率只作敏感性分析：对 1 次成功的观测，其 p 值随种子预算单调变化。
* 单次 JEPA 成功不可解读：以一个事件越过地板不构成控制能力的证据（本实验中它甚至没越过）。
