# KW-MOON-0001 — 月球漫游车解析式世界模型 v0：可实现性验证

- 日期：2026-09-11
- 类型：**预注册实验**（先锁判据 K1–K7，再跑）
- 上级问题：`docs/research/LUNAR_WORLD_MODEL_v0.md` §「为什么学习型月球世界模型做不出来」
- 目标：验证一个**解析式（非学习）世界模型** `s_{t+1}=f(s_t,a_t)` 是否能在**零训练、零依赖、单机**条件下，
  用**真实 LOLA 高程**给出物理自洽、可机器校验、可复现的状态预测。

## 0. 为什么不做学习型月球世界模型

世界模型的学习信号是「动作 → 结果」的因果序列。月球上该数据**不存在**：

| 世界模型需要 | 月球实际有 | 判定 |
|---|---|---|
| 精确几何高程 | LOLA 全球 118 m、南极区域到 5 m/px | 充足 |
| 海量连续影像序列 | LROC 静态影像 100 万张以上、0.5 m/px | 形态不对（俯视静态） |
| 动作→结果因果对 | 人类共在月面开过 4 台车；玉兔二号累计约 1.6 km | **唯一死穴** |

⇒ 训练是不可行的（不是算力问题，是观测次数问题）。
⇒ 因此本实验只做**解析式世界模型**：动力学由公开刚体力学给出，地形由真实高程给出，**无训练**。

## 1. 设计与公式（预注册，跑前锁定）

状态 `s = (x, y, ψ, v, battery_Wh, t_s)`；动作 `a = (v_cmd, ψ_rate)`；`dt` 固定。

爬坡上限取三个独立约束的最小值，全部闭式：

| 约束 | 物理 | 闭式解 | 依赖 |
|---|---|---|---|
| (a) 牵引 | `sinθ + Crr·cosθ ≤ μ·cosθ` | `θ_t = arctan(μ − Crr)` | 与质量无关 |
| (b) 扭矩 | `m·g·(sinθ+Crr·cosθ)·r_w/(n_w·gear) ≤ T_max` | `θ_T = arcsin(A_T/R) − φ` | ∝ 1/m |
| (c) 功率 | `m·g·(sinθ+Crr·cosθ)·v/η ≤ P_max` | `θ_P(v) = arcsin(A_P/R) − φ` | ∝ 1/(m·v) |

其中 `R=√(1+Crr²)`、`φ=arctan(Crr)`、`A_T=T_max·n_w·gear/(m·g·r_w)`、`A_P=P_max·η/(m·g·v)`。

能量：`E_traction = m·g·(sinθ+Crr·cosθ)·d/η`；`E_total = E_traction + P_avionics·dt`。

**参数来源声明**：`RoverParams` 的全部数值为**设计假设**（玉兔二号量级 140 kg，
μ/Crr/P_max/T_max 取公开仿真工具的常见量级），**未经任何车辆实测标定**。本仓库无车辆数据。

## 2. 判据（预注册，K1–K7，全过才 PASS）

| 编号 | 判据 | 通过阈值 |
|---|---|---|
| **K1** | **分量单调性**：`θ_t` 对 μ 严格递增；`θ_P` 对 m 严格递减、对 P_max 严格递增、对 v 严格递减；`θ_T` 对 m 严格递减、对 T_max 严格递增 | 每项 5 点网格上**严格**单调（差分符号全同） |
| **K2** | **组合上限一致性**：`θ_limit(v)` 恰等于 `min(θ_t, θ_T, θ_P(v))` | 最大绝对偏差 < 1e-12 rad |
| **K3** | **功率闭式自洽**：在 `θ = θ_P(v)` 处，`required_power(θ,v)/P_max − 1` | 相对误差 < 1e-9 |
| **K4** | **平地能量闭式**：θ=0、匀速走 d 米，`E_traction` 必须等于 `Crr·m·g·d/η` | 相对误差 < 1e-9 |
| **K5** | **阻挡门控**：命令驶入坡度 > `θ_limit` 的格点 | `blocked=True`、`reason=slope_exceeds_limit`、位移**严格 = 0.0** |
| **K6** | **电池终止**：初始电量极小 | 终止原因 = `battery_depleted`；末态电量 ≥ 0 且 < 初始电量 |
| **K7** | **确定性与数值稳健**：同 seed 两次运行 SHA256 一致；200 个随机场景（固定 seed） | 哈希逐位相同；NaN/Inf 计数 = 0 |

**Kill 规则**：K1–K7 任一项 FAIL ⇒ 结论记为 `FAILED`，**不调参、不改判据**，如实记录后另开预注册。

**结局均视为有效结果**（含全部失败），只有「预注册后改判据」才是流程违规。

## 4. 已知限制（预注册时即声明，跑前不可事后减少）

1. **分辨率致命限制**：16 ppd ⇒ 赤道约 **1.9 km/像素**；坡度基线（n_cells=2）约 **3.8 km**。
   这**远大于漫游车尺度**，因此坡度是**区域地形趋势**，**不是**车轮级可通过性判据。
   真实工程用 0.02 m（导航相机 DEM）至 5 m/px（NASA PGDA Product 78）级产品。
   本 v0 是**方法论骨架 + 校验框架**，换 DEM 即可升级，但**当前分辨率下任何车轮级结论都无效**。
2. **滑移模型是最弱一环**：`slip = min(slip_max, slip_k·(θ/θ_limit)²)` 是**参数化假设**，
   不是轮-土力学（terramechanics）仿真；无实测标定。
3. **光照为简化星历**：忽略轨道偏心率与章动，幅度精度不足 10°，只可用于「在不在照明区」的判定，
   **不可用于精密能量预算**。真实工具用 NASA SPICE。
4. **无地形自遮挡**：不做 ray-marching，极区永久阴影区会被误判为受照。
5. **非学习型**：本模型**没有神经网络、没有训练、不能生成图像**。不得表述为「学习型世界模型」。
6. **证据等级 E1**：单一解析模型、单一数据源、**无第三方验证、无外部标定**。
